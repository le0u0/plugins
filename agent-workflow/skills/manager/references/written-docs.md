# Written Docs

Applies to every markdown file an agent writes, such as `plan.md`, `think.md`, `triage.md`, `diagnose.md`, `checklist.md`, `jobs.md`, `review.md`. Write only the docs [storage.md](storage.md) lists: create one when it is missing, and update it in place when it exists. A second version gets no new file, such as `plan_2.md`.

- Every point is one line, at most 15 words. Split or cut longer ones.
- Fragments. Drop articles, filler, hedging, and restated context: "Export button shows when flag off. Hide it." not "The Export button is currently displayed even though the preference is disabled, so it should be hidden."
- Code, identifiers, paths, and error strings stay exact.
- Keep to the present state: no history, dates, other findings, or how a decision was reached.
- Detail only the next reader needs to act goes in the point; reference detail goes in `<sub>`.
